# Spacewarm: NASA Space Particle Mapping & Live Space IDE

Spacewarm is an interactive 3D full-stack application integrating NASA APIs for orbital space particle visualization, biological radiation risk analysis, and in-orbit coding workflows.

## Features
- **3D Orbital Earth Simulation:** Three.js-rendered planetary background with particle fields.
- **Floating HUD & Live IDE:** Sci-fi glassmorphism coding terminal floating directly in space with orbital physics motion.
- **Radiation Telemetry:** Real-time particle classification (Solar protons, cosmic rays, and ions) to assess biological risks.
